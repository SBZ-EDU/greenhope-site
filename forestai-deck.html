سهیل سبزواری

مشکل

  • استارتاپ‌های سبز گرنت‌ها را از دست می‌دهند: کشف گرنت دستی و کند است
  • پیدا کردن شرکت همکار مناسب ماه‌ها طول می‌کشد
  • ساختار قرارداد (JV / لیسانس / SPV) به وکیل گران نیاز دارد
  • مهلت‌ها می‌گذرند قبل از اینکه مذاکره شروع شود

راهکار

  • یک فضای کاری هوشمند: کشف گرنت، تطبیق شرکت، پیش‌نویس شرایط قرارداد
  • فهرست رتبه‌بندی‌شده شرکا با نمره و دلیل، به‌صورت زنده
  • یادداشت حقوقی خودکار: تقسیم پتنت، بندها، تایم‌لاین
  • استراتژی قدم‌به‌قدم از امروز تا ارسال

چطور کار می‌کند؟

  • ۱. یک گرنت انتخاب کن (NSF ،UKRI ،USDA و...)
  • ۲. هوش مصنوعی بهترین شرکت‌ها را رتبه می‌کند: نمره + نقش + قدم بعدی
  • ۳. مشاور، ساختار همکاری و نکات قراردادی را می‌نویسد
  • ۴. تایم‌لاین تو را به میز مذاکره می‌رساند

موتور هوش مصنوعی

  • Claude Haiku 4.5 برای تطبیق زنده (استریم SSE)
  • Claude Sonnet 4.6 برای تحلیل عمیق
  • بک‌اند FastAPI + فرانت React با خروجی ساخت‌یافته JSON
  • سورس کامل + پرامپت‌ها برای شرکا در دسترس است

دستاوردها

  • دموهای زنده: ماژول تطبیق + مشاور حقوقی
  • نمونه‌های واقعی: یادداشت‌های NSF / UKRI / USDA
  • ۶+ شرکت نمونه و ۴ گرنت فعال به‌صورت پیش‌فرض
  • رابط دوزبانه (فارسی/انگلیسی)، تست‌شده با کاربر واقعی

درخواست ما

  • اسپانسرها: تأمین استقرار پایلوت و مقیاس API
  • شرکای تجاری: توسعه مشترک و لیسانس ماژول‌ها
  • دانشگاه‌ها: همکاری پژوهشی + مطالعات اعتبارسنجی
